# Fisher Research Claude Skills

Claude Code plugins published by [Fisher Research](https://fisherresearch.dev).

## Install

Add this repository as a plugin marketplace, then install a plugin:

```text
/plugin marketplace add Fisher-Research/claude-plugins
/plugin install cold-email@fisher-research
```

## Plugins

- [cold-email](plugins/cold-email/README.md): find leads with Firecrawl and Apollo, write personalized cold emails, and upload them to Instantly with one command.
